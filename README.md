# Employee Analytics

This project analyzes employee data to identify insights related to age, salary, department, gender, job role, and employment status. 
The data was cleaned by handling missing values, filling missing Age and Salary with mean values, removing duplicates, and cleaning inconsistent data.
The analysis was performed using Python and Excel, and an interactive dashboard was created using Power BI with KPIs, charts, and filters. 
Tools used: Python, Pandas, Excel, Power BI, and GitHub.
